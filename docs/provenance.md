# Provenance

## Permitted sources

- RFC 6143 and its published errata
- IANA RFB assignments
- Kitty graphics protocol documentation
- POSIX and platform documentation
- Apple public Screen Sharing documentation
- Project-generated wire vectors, synthetic inputs, and tests
- OpenSSL and CommonCrypto provider documentation

## Prohibited sources

Do not inspect or reuse source, executable contents, symbols, runtime internals,
memory, or control flow from proprietary software or software whose license is
outside the project allowlist.

## Apple release status

The Apple feature set is not approved for release. Release requires a written
repository-owner governance decision under ADR-0013 and any required counsel
review.
